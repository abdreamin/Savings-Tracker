📊 Google Sheets Sync

Sign in with Google to sync your data across devices. Everything is saved to a single private Google Sheet in your own Drive — Coffee Savings Tracker — so you can open and read it any time. Nothing is shared with anyone.

Not connected
▸ One-time setup (takes ~5 min)
Step 1: Go to console.cloud.google.com and create a new project (or pick an existing one).

Step 2: Go to APIs & Services → Library and enable both the Google Sheets API and the Google Drive API.

Step 3: Go to APIs & Services → OAuth consent screen. Choose External, fill in app name + your email, add your email as a test user. Save.

Step 4: Go to APIs & Services → Credentials → Create Credentials → OAuth client ID. Application type: Web application. Add your hosting URL to "Authorized JavaScript origins" (e.g. https://yoursite.com). Copy the Client ID.

Step 5: Paste it below and click Save.
